# Terra CRM

Прототип CRM-системы для отдела продаж застройщика. Интерактивная шахматка, цифровые профили клиентов, воронка продаж и дашборд РОП.

Стек: чистый HTML + CSS + ванильный JavaScript. Никаких зависимостей, ничего не нужно собирать.

---

## Как открыть

Просто открой `index.html` в браузере — двойной клик или перетащи в окно браузера. Всё работает локально.

Если хочется живой версии в интернете, можно включить **GitHub Pages**:
1. GitHub → Settings → Pages → Source: `Deploy from branch` → ветка `main` → `/ (root)`
2. Через минуту сайт будет доступен по адресу `https://<username>.github.io/Probnik/`

## Структура проекта

```
Probnik/
├── index.html        # разметка всех 4 вкладок
├── styles.css        # все стили (палитра, сетка, компоненты)
├── README.md
└── js/
    ├── data.js       # все тестовые данные: клиенты, менеджеры, объекты, цифры
    ├── utils.js      # глобальное состояние, генератор шахматки, helpers
    ├── chess.js      # вкладка «Шахматка» + боковая панель объекта
    ├── clients.js    # вкладка «Цифровые профили клиентов»
    ├── funnel.js     # вкладка «Воронка и статистика»
    ├── dashboard.js  # вкладка «Дашборд РОП»
    └── app.js        # переключатели, поиск, календарь, уведомления, init
```

### Что где править

| Хочу изменить… | Открой… |
|---|---|
| Тестовых клиентов, цены, менеджеров, объекты | `js/data.js` |
| Цвета, шрифты, отступы, цвета статусов | `styles.css` (секция `:root` сверху) |
| Логику шахматки, фильтры, боковую панель | `js/chess.js` |
| Карточку клиента, AI-подсказку | `js/clients.js` |
| Диаграммы воронки/статистики | `js/funnel.js` |
| Виджеты дашборда РОП | `js/dashboard.js` |
| Глобальный поиск, календарь, уведомления | `js/app.js` |
| HTML-разметку любой вкладки | `index.html` |

Скрипты подключаются в нужном порядке: сначала `data.js`, потом `utils.js`, потом вкладки, и в конце `app.js`, который запускает `init()`.

## Как работать в паре с Claude

У нас два режима совместной работы:

**1. Ты редактируешь сам**
- Открой нужный файл (например, `js/data.js`) прямо на GitHub в браузере или локально
- Внеси правки, закоммить, запушь
- Я подхвачу твои изменения, когда ты в следующий раз меня позовёшь

**2. Просишь меня**
- Скажи, что нужно сделать («добавь поле email в карточку клиента», «сделай тёмную тему», «добавь сортировку в таблицу менеджеров»)
- Я внесу правки, закоммичу и запушу
- Ты увидишь дифф в GitHub и сможешь принять / откатить / поправить

**Ветка для работы:** `claude/intelligent-keller-tj8si2`. Когда фича готова — мерджим в `main`.

### Что удобно попробовать первым

- Заменить тестовых клиентов в `js/data.js` на реальные из твоего отдела
- Подкрутить палитру в `styles.css` под фирменные цвета застройщика
- Добавить ещё одну вкладку (например, «Звонки» или «Сделки в работе»)
- Сохранить статусы помещений в `localStorage`, чтобы клик-изменения не сбрасывались при перезагрузке
- Подключить реальный API вместо `BUILDINGS`/`CLIENTS`

Когда понадобится — пиши, какой кусок брать.
