# ⚓ Морской бой — онлайн на двоих

Классический «Морской бой» 10×10, в который можно играть вдвоём **с разных компьютеров** через интернет. Свой сервер поднимать не нужно — ходы передаются через публичный сервер сообщений (MQTT поверх WebSocket), поэтому игра проходит почти через любые роутеры, Wi-Fi и мобильный интернет.

## Как поиграть с другом

1. Оба открываете страницу игры (`battleship/index.html`).
2. Один нажимает **«Создать игру»** и получает код из 4 символов.
3. Отправляет код другу (в мессенджере, по телефону — как угодно).
4. Друг вводит код и нажимает **«Присоединиться»**.
5. Оба расставляют корабли (кнопка 🎲 перемешивает расстановку) и жмут **«Готов к бою!»**.
6. Играете: попал — ходишь ещё. Кто первым потопит весь флот, тот победил.

## Игра на одном компьютере

Если играете вдвоём за одним устройством, в меню есть кнопка **«🎮 Игра на двоих за одним ПК»**. Тогда:

1. Игрок 1 расставляет корабли и жмёт «Готов».
2. Появляется экран «Передайте компьютер» — он прячет поле, чтобы соперник его не увидел. Передаёте устройство, второй игрок нажимает кнопку и расставляет свои корабли.
3. В бою ходите по очереди: после промаха снова появляется экран передачи, а при попадании стреляете ещё раз. Компьютер переходит от одного к другому — как в бумажном варианте.

## Где открыть страницу

Любой из вариантов:

- **GitHub Pages** (удобнее всего): включите Pages в настройках репозитория (Settings → Pages → ветка `main`), и игра будет доступна по адресу
  `https://ruslanb127-png.github.io/Probnik/battleship/`
- **Просто файлом**: скачайте `index.html` и откройте в браузере — игра работает и с локального файла (нужен только доступ в интернет).

## Правила

- Поле 10×10, корабли: 1×4, 2×3, 3×2, 4×1.
- Корабли не могут касаться друг друга (даже по диагонали).
- При попадании — дополнительный ход.
- Клетки вокруг потопленного корабля помечаются автоматически.
- После окончания партии можно сыграть реванш, не пересоздавая игру.

## Если по сети не соединяется

Онлайн-режим гоняет ходы через публичные MQTT-брокеры по WebSocket. Игра подключается сразу к нескольким серверам и ищет соперника на любом общем — это надёжно проходит через большинство сетей. Но если у обоих строгий корпоративный/учебный фаервол, соединение может не подняться. Тогда: попробуйте мобильный интернет (раздача с телефона) или играйте в режиме «за одним ПК».
