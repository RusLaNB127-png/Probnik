# 🎮 PIXEL ARCADE

Игровая платформа в ретро-8-бит стиле. Пользователи регистрируются по нику и паролю, заходят под своим аккаунтом и играют в игры платформы. Первая игра — **Морской бой**; остальные плитки («Крестики-нолики», «Змейка», «Мемори») — заготовки под будущие игры.

Всё работает без сервера (один HTML-файл): аккаунты и рекорды хранятся в браузере, ходы онлайн-игр идут через публичные MQTT-брокеры.

## Аккаунты и лидерборд

- На входе — **регистрация** (ник + пароль) или **вход**. Пароль хранится не открытым текстом, а в виде хеша SHA-256 с солью.
- После входа игрок сразу попадает в **лидерборд** платформы (общий рейтинг всех зарегистрированных на этом устройстве).
- Лидерборд **обновляется автоматически** по результатам партий: победителю +1 победа, проигравшему +1 поражение. Сортировка по победам, топ-3 с медалями 🥇🥈🥉, ваша строка подсвечена.
- Онлайн: каждый игрок засчитывает свой результат в свой аккаунт. Локальная игра «за одним ПК»: если оба ника — зарегистрированные аккаунты, засчитываются оба.

> **Важно про хранение.** Пока платформа без сервера, аккаунты и лидерборд живут в браузере конкретного устройства — то есть у каждого устройства свой список. Это осознанный выбор для быстрого старта: код структурирован так, чтобы при переезде на сервер те же экраны (регистрация, лидерборд) стали общими для всех, без переписывания интерфейса. Пароль хеш локально — это защита от подглядывания, а не полноценная серверная авторизация.

## Морской бой

Классика 10×10, флот 4-3-3-2-2-2-1-1-1-1. Игра по сети (по коду из 4 символов) или за одним компьютером. Ручная расстановка кораблей (палитра + поворот + подсветка) или случайная. Правило «попал — ходишь ещё», детализированные корпуса кораблей, кнопка выхода, реванш. Подробности — в истории коммитов.

## Дальнейшие шаги (когда будет сервер)

- Перенести аккаунты и лидерборд на сервер → общие для всех, вход с любого устройства.
- Добавить новые игры в каталог (плитки уже есть).
